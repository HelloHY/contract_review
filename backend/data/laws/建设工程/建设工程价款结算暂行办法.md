# 建设工程价款结算暂行办法（财建〔2004〕369号）——审查要点

## 预付款

**第十二条** 包工包料工程的预付款按合同约定拨付，原则上预付比例不低于合同金额的10%，不高于合同金额的30%，对重大工程项目，按年度工程计划逐年预付。

**第十三条** 在具备施工条件的前提下，发包人应在双方签订合同后的一个月内或不迟于约定的开工日期前的7天内预付工程款。发包人不按约定预付，承包人应在预付时间到期后10天内向发包人发出要求预付的通知，发包人收到通知后仍不按要求预付，承包人可在发出通知14天后停止施工，发包人应从约定应付之日起向承包人支付应付款的利息（利率按同期银行贷款利率计），并承担违约责任。

## 进度款

**第十三条** 工程进度款结算方式：（一）按月结算与支付。即实行按月支付进度款，竣工后清算的办法。合同工期在两个年度以上的工程，在年终进行工程盘点，办理年度结算。（二）分段结算与支付。即当年开工、当年不能竣工的工程按照工程形象进度，划分不同阶段支付工程进度款。

工程进度款支付比例：根据确定的工程计量结果，承包人向发包人提出支付工程进度款申请，14天内，发包人应按不低于工程价款的60%，不高于工程价款的90%向承包人支付工程进度款。

## 竣工结算

**第十四条** 工程完工后，双方应按照约定的合同价款及合同价款调整内容以及索赔事项，进行工程竣工结算。竣工结算审查时限：

| 送审金额 | 审查时限 |
|---|---|
| 500万元以下 | 20天 |
| 500万-2000万元 | 30天 |
| 2000万-5000万元 | 45天 |
| 5000万元以上 | 60天 |

> 审查要点：进度款支付比例低于60%的条款对承包人不利；结算审核时限与逾期后果应明确约定。
